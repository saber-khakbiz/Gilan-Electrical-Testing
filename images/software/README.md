# Software screenshots

Put AmperCard screenshots here (PNG, a full window capture at 100% scaling
works best; Win+Shift+S, then "Window snip").
Then list them in software/products.js under "screenshots", for example:

    screenshots: [
      { src: "../images/software/ampercard-main.png", caption: "..." }
    ],

The page draws the window frame itself, so crop out the real title bar if you like.
